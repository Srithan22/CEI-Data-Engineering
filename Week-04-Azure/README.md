# Azure Cloud Fundamentals and Data Pipeline using ADF

In this assignment, I worked with Azure Storage and Azure Data Factory to create a simple data pipeline.

## Steps Completed

Created a Resource Group in Azure.

Created a Storage Account and Blob Container.

Uploaded the CSV file to Blob Storage.

Created Azure Data Factory.

Created a Linked Service to connect ADF with Storage.

Created source and destination datasets.

Used Get Metadata activity to check file details.

Used Copy Data activity to move data from source to destination.

Ran the pipeline using Debug mode.

Checked IAM roles and permissions.

## Pipeline Flow

Source CSV File → Get Metadata → Copy Data → Destination Container

## Brief Insights

Learned how Azure resources are created and managed.

Understood how Blob Storage is used to store files.

Learned how Azure Data Factory can move data between locations.

Got hands-on experience with Get Metadata and Copy Data activities.

Learned how to monitor pipeline execution and check results.

## Result

The pipeline ran successfully and the CSV file was copied from the source container to the destination container without any errors.
