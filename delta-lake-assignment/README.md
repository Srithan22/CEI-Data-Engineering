# Delta Lake Assignment

## Objective
Perform incremental data processing using Delta Lake.

## Technologies Used
- Python
- PySpark
- Delta Lake
- Databricks

## Workflow
1. Load dataset
2. Clean data
3. Create incremental dataset
4. Perform MERGE
5. Validate results

## Learning Outcomes
- Learned how to create Delta tables.
- Learned MERGE operations.
- Learned incremental data processing.
- Learned basic data validation.
